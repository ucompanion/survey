# [2단계] 백엔드 다중 프로젝트 지원 업데이트 지시서

이 프롬프트는 현재 **프론트엔드 작업(1단계)이 완벽하게 완료된 상태**에서, 향후 **남은 백엔드 작업(2단계)**을 수행하기 위해 다음 AI에게 전달할 작업 지시서입니다. 
고객 서비스 실사용 기간이 끝나고 서버를 고쳐도 되는 안전한 타이밍이 오면, 이 파일의 내용을 복사하여 새로운 AI에게 지시해 주시면 됩니다.

---

## 👨‍💻 System/Role
당신은 풀스택 웹 개발자입니다. 현재 바닐라 JS(프론트엔드)와 Node.js(백엔드)로 구성된 설문지 앱의 아키텍처 중 프론트엔드는 이미 다중 프로젝트를 지원하도록 완벽하게 개편되었습니다. (파라미터 자동 라우팅 분기, 로컬 임시 백업, 전용 어드민 대시보드 UI 등 모두 구현 완료)
당신의 핵심 목표는 프론트엔드의 새 구조에 발맞춰 **"백엔드(`server.js`)를 수정하여 다중 프로젝트(JSON 파일)를 분리 저장하고, 전체 프로젝트 목록을 프론트엔드 대시보드에 전달하는 API를 구현"**하는 것입니다.

## 📋 Task Description (작업 지시 사항)

다음 Step 1~3에 따라 코드를 수정하고 결과를 보고해 주세요.

### Step 1: 백엔드 동적 파일 저장 로직 수정 (`server.js`)
1. 기존에 고정되어 있던 단일 파일 `survey_data.json` 저장 로직을 제거하고, 동적으로 파일을 생성/읽기/삭제 하도록 변경합니다.
2. `/api/save` 및 `/api/delete` 요청(POST)을 받으면 전달된 JSON body에서 `projectId`를 추출하세요.
3. `/api/load` 요청(GET)을 받으면 URL 쿼리 파라미터에서 `projectId`를 추출하세요.
4. 추출한 `projectId`를 바탕으로 저장할 파일 이름을 `survey_data_${projectId}.json` 형식으로 동적 생성하여 데이터를 읽고 쓰도록 모든 API(`load`, `save`, `delete`) 로직을 수정하세요.

### Step 2: 관리자 대시보드용 목록조회 API 추가 (`server.js`)
1. `/api/list` 라는 새로운 GET 엔드포인트를 추가하세요.
2. 이 API는 서버의 데이터 디렉토리(현재 폴더)를 스캔하여 `survey_data_*.json` 패턴을 가진 모든 백업 파일의 목록을 찾고, 해당 파일들의 내용을 모두 읽어 배열 형태로 프론트엔드에 반환해야 합니다. 반환 데이터에는 최소한 `projectId`와 `site_name`이 매핑되어 포함되어야 합니다.

### Step 3: 프론트엔드 대시보드 통신 연동 (`script.js`)
1. 프론트엔드의 `script.js` 파일 맨 아래에는 이미 `renderAdminDashboard()` 라는 완벽한 대시보드 화면 UI 함수가 구현되어 있습니다.
2. 현재는 서버 연결 실패 시를 대비해 로컬 스토리지(`localStorage`)에 저장된 임시 백업 데이터만 긁어와서 보여주고 있습니다.
3. 이를 수정하여, 대시보드를 렌더링할 때 새롭게 만든 `/api/list` 백엔드 엔드포인트를 함께 호출하도록 변경하세요.
4. 서버에서 받아온 "실제 저장된 데이터" 목록을 기반으로 대시보드 목록이 렌더링되도록 코드를 고도화하세요.

## ⚠️ 제약 사항 (Constraints)
- 프론트엔드의 전체적인 라우팅 구조(랜딩페이지 -> 파라미터별 폼 분기)와 UI/UX 디자인은 이전 작업자가 완벽하게 세팅해 두었으므로 절대 훼손하지 마세요.
- 백엔드 코드(`server.js`) 수정 시 런타임 에러가 발생하지 않도록 주의하고, 완료되면 프론트와 통신 테스트를 진행하세요.
